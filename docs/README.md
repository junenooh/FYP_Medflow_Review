# Documentation map

- `architecture/` — system boundaries, data flow and UC sequencing.
- `data/` — ERD and database documentation.
- `design/` — MedFlow brand and interface design guides.
- `use-cases/` — algorithms, formulas and business decisions.
- `images/` — diagrams referenced by the documents above.

Use lowercase kebab-case filenames for new documents and keep generated exports out of Git.
