Design guide

How the MedFlow planner platform looks and behaves on screen. One shell, five pages — Dashboard, Product Relationships, Replenishment, Layout and Digital Twin — all built on the DHL co-branded palette and type.

Design system

Foundations

Colour and type come from the brand guide. The three things below are what keep every screen feeling like the same product: a 4-pixel spacing scale, two corner radii, and a twelve-column grid.

Spacing steps in pixels. Use these; never 10, 15 or 20.

Corners

6 px — buttons, pills, inputs
0 — cards, panels, tables

Panels are square, like DHL's own layout blocks. Only interactive controls are rounded.

Grid

12 columns, 24 px gutters, content max-width 1280 px.

Design system

Layout

Every screen shares one frame. A DHL-yellow top bar that never scrolls away, a fixed sidebar with one entry per use case, and a sand-coloured working area where white panels carry the data.

Design system

Charts

Colour in a chart carries meaning, never decoration. The functional palette does the work; DHL red marks the one thing that matters — the recommendation, the critical value — and everything else stays grey. DHL yellow is never a data colour.

Product relationships

Companion SKUs from association-rule mining. Edge weight is the affinity band; node size is pick velocity; the red node is a critical SKU.

Do

  • Label axes and units.
  • One meaningful colour per series.
  • Sort bars and slices by value.
  • Put numbers on the chart when they matter.

Don't

  • Use DHL yellow for data.
  • Stack more than five categories.
  • Add 3D, gradients or shadows to data.
  • Leave gridlines heavier than the data.

Page rhythm

Page header: title, context line, and the one primary action.
Metric row: three or four numbers that answer "how bad is it right now?"
Working area: chart on the left, the actionable list on the right.
Detail: selecting a row opens its rationale — the values a planner can audit.

Same rhythm on all five pages. A planner should never have to hunt for the number or the button.
